# To-Do List Application

This is a simple To-Do List application developed using Python.

The project allows users to keep track of their daily tasks. Users can add new tasks, view all saved tasks, mark tasks as completed, and delete tasks when they are no longer needed. The task data is stored in a JSON file so that it remains available even after closing the program.

## Features

- Add new tasks
- View saved tasks
- Mark tasks as completed
- Delete tasks
- Store task data using JSON
