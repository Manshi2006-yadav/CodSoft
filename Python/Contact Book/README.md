# Contact Book

This is a simple Contact Book project developed using Python as part of my learning journey and internship tasks.

The application allows users to store and manage contact details such as name, phone number, email, and address. Contact information is saved in a JSON file so that the data remains available even after closing the program.

## Features

- Add new contacts
- View all saved contacts
- Search contacts by name or phone number
- Update existing contact details
- Delete contacts
- Data stored using JSON
