# Password Generator

This is a simple Password Generator built using Python.

The main purpose of this project is to generate strong and random passwords based on the length entered by the user. It uses a combination of letters, numbers, and special characters to create secure passwords.

## Features

- Generate random passwords
- User can choose the password length
- Includes uppercase and lowercase letters
- Includes numbers and special characters
- Easy to use and beginner-friendly

## Project Structure

```text
PasswordGenerator/
│
├── generator.py
├── main.py
└── README.md
```

## Technologies Used

- Python 3
- Random Module
- String Module

## How It Works

1. The user enters the desired password length.
2. The program combines letters, digits, and special symbols.
3. A random password is generated.
4. The generated password is displayed on the screen.

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code or any Python IDE.
3. Run the following command:

```bash
python main.py
```
